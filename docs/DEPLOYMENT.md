# Deployment

Recommended production targets:

- Frontend: Vercel
- Backend: Railway
- Database: Neon PostgreSQL

Required variables include:

- `NEXT_PUBLIC_API_URL`
- `APP_ENV=production`
- `DATABASE_URL`
- `SYNC_DATABASE_URL`
- `AI_PROVIDER=openai`
- `OPENAI_API_KEY`
- `OPENAI_MODEL`
- `GITHUB_TOKEN`
- `ALLOWED_ORIGINS`
